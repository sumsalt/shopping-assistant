# 凑单计算器

一款智能的购物凑单工具，帮你快速计算出最优凑单方案，轻松实现满减优惠最大化。

## ✨ 核心功能

### 🧮 智能计算
- 支持批量输入多个商品价格
- 自动计算满足满减条件的最佳商品组合
- 提供多个备选方案供选择

### 📦 订单管理
- 支持多个订单同时凑单
- 智能分配商品到不同订单
- 实时显示每个订单的总价

### 🎯 灵活配置
- 设置凑单价格（满减金额）
- 设置订单数量
- 标记必选商品

### 📊 结果展示
- 最优方案突出显示
- 订单分配详情可视化
- 商品使用情况统计
- 超出目标金额计算

## 🚀 使用场景

### 场景 1：满减凑单
```
输入商品价格：59.9元、88元、129.5元
凑单目标：满200减50
结果：自动计算出总价最接近200元的组合
```

### 场景 2：多单凑单
```
需要凑满 3 个订单，每个订单满199减20
输入 10 件商品的价格
结果：智能分配商品到3个订单，每个订单都接近199元
```

### 场景 3：必选商品
```
有 3 件必须购买的商品
标记为"必选"
系统会强制包含这些商品，再补充其他商品
```

## 💡 使用方法

### 第一步：输入商品
1. **批量输入**：在输入框中输入多个价格，用逗号或空格分隔
   - 示例：`59.9,88,129.5,45,67`
2. **手动添加**：逐个输入商品价格
   - 点击"添加商品"增加输入框
   - 点击"−"删除不需要的商品

### 第二步：设置目标
1. **凑单价格**：输入满减金额（例如满200减50，就输入200）
2. **订单数量**：设置需要凑满的订单数（默认1个）

### 第三步：查看结果
1. 点击"计算凑单方案"
2. 查看**最优方案**（最接近目标价格的组合）
3. 浏览**其他方案**，选择最合适的

### 第四步：查看详情
- 查看每个订单分配的商品
- 了解未使用的商品
- 对比不同方案的价格差异
