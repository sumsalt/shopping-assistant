# 凑单计算器

一款智能的购物凑单工具，帮你快速计算出最优凑单方案，轻松实现满减优惠最大化。

## 🎯 核心功能

### 智能凑单计算
- **批量输入**：支持一次输入多个商品价格
- **智能分配**：自动计算满足满减的最佳组合
- **多方案对比**：提供多个备选方案，选择最适合的

### 灵活配置
- **凑单价格**：设置满减金额（如满200减50）
- **订单数量**：支持多订单同时凑单
- **必选标记**：强制包含指定商品

### 结果可视化
- **最优方案**：突出显示最接近目标的组合
- **订单详情**：清晰展示每个订单的商品和价格
- **统计数据**：总价、差额、使用商品数一目了然

## 💡 使用场景

### 场景 1：满减凑单
**问题**：有 5 件商品，满 200 减 50，怎么组合最划算？

**使用方法**：
1. 输入商品价格：59.9、88、129.5、45、67
2. 设置凑单价格：200
3. 点击计算

**结果**：自动计算出总价最接近 200 元的组合

### 场景 2：多单凑单
**问题**：需要凑满 3 个订单，每个订单满 199 减 20

**使用方法**：
1. 输入 10 件商品的价格
2. 设置凑单价格：199
3. 设置订单数量：3
4. 点击计算

**结果**：智能分配商品到 3 个订单，每个都接近 199 元

### 场景 3：必选商品
**问题**：有 3 件必须买的商品，再凑满 200 元

**使用方法**：
1. 输入所有商品价格
2. 将必须买的商品标记为"必选"
3. 点击计算

**结果**：强制包含必选商品，再补充其他商品

## 🚀 快速上手

### 第一步：输入商品

**批量输入**（推荐）
```
输入框中输入：59.9,88,129.5
支持逗号、空格分隔
```

**手动添加**
```
点击"添加商品"按钮
逐个输入商品价格
```

### 第二步：设置目标

**凑单价格**
- 输入满减金额（如满200减50，输入200）

**订单数量**
- 设置需要凑满的订单数（默认1个）

### 第三步：查看结果

**最优方案**
- 绿色卡片显示最接近目标的组合
- 查看订单分配详情

**其他方案**
- 浏览多个备选方案
- 选择最满意的组合

## 📊 结果说明

### 最优方案
- **总价格**：所有选中商品的总价
